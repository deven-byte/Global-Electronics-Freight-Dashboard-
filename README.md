# 🚚 Global Electronics Freight Analytics Dashboard

## 📌 Project Overview

This project is an end-to-end Freight & Logistics Analytics Dashboard developed entirely in Microsoft Excel. The dashboard provides a comprehensive view of shipment operations, freight costs, delivery performance, customer contributions, and transportation efficiency through interactive visualizations and KPI tracking.

The objective was to transform raw logistics data into meaningful business insights that support operational monitoring and decision-making.

---

## 🎯 Business Problem

Logistics teams often struggle to monitor shipment performance, delivery timelines, transportation costs, and customer activity from large datasets.

This dashboard was created to:

- Track shipment performance
- Monitor freight spending
- Evaluate transport mode efficiency
- Measure delivery reliability
- Identify key customers
- Support data-driven logistics decisions

---

## 🛠 Project Workflow

### 1. Data Cleaning
- Removed inconsistencies and duplicate records
- Standardized categorical values
- Validated shipment and cost information

### 2. Data Preparation
- Structured raw data for analysis
- Created calculated fields and business metrics
- Organized data for Pivot Table reporting

### 3. Data Analysis
- Analyzed shipment volume trends
- Evaluated freight cost distribution
- Assessed customer contribution
- Measured delivery performance

### 4. Dashboard Development
- Built interactive Pivot Tables
- Designed Pivot Charts
- Added slicers for dynamic filtering
- Developed KPI cards for executive reporting

---

## 📊 Dashboard Features

### KPI Metrics
- Total Shipments
- Total Freight Cost
- Average Transit Days
- On-Time Delivery Percentage

### Interactive Filters
- Year
- Transport Mode
- Shipment Status
- Product Category
- Origin Country
- Import/Export Type

### Dashboard Visualizations

#### 📦 Units by Product
Analyze shipment quantity across product categories.

#### 🌍 Freight Cost by Origin
Compare freight costs across different countries.

#### 📈 Shipment Trend by Month
Track monthly shipment activity and seasonality.

#### ⏱ On-Time vs Late Deliveries
Evaluate logistics performance and service reliability.

#### 👥 Top 5 Customers
Identify highest-value customers.

#### 🚛 Freight Cost by Transport Mode
Compare transportation costs across Air, Rail, Road, and Sea.

---

## 🔍 Key Insights

- Identified seasonal shipment patterns and peak logistics periods.
- Measured delivery performance with more than 55% on-time shipments.
- Determined the most expensive origin locations contributing to freight costs.
- Highlighted top customers driving logistics volume.
- Compared transportation modes to identify cost-efficient options.
- Analyzed product categories contributing the highest shipment volumes.
